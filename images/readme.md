# Screenshot Assets

Place screenshots here for the VS Code Marketplace listing.

## Required screenshots

1. **hero.png** — Main request builder with a response visible (used as the hero image in README)
2. **collections.png** — Collections sidebar with folders and requests
3. **code-export.png** — Code export panel showing generated code

## Guidelines

- Use a dark VS Code theme for consistency with the gallery banner
- Recommended width: 1200–1400px
- PNG format, compress to keep each file under 200KB
- Capture with a realistic request/response (e.g. jsonplaceholder.typicode.com)
